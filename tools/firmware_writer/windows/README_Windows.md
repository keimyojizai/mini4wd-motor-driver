# Mini4AI Firmware Writer for Windows

## 使い方

1. ZIPを右クリックして「すべて展開」します。
2. 展開したフォルダの `RUN_ME_FIRST_Flash_Mini4AI_Windows.bat` をダブルクリックします。
3. 初期BLEデバイス名を入力します。空欄なら `Mini4AI` になります。
4. 表示に従って書き込みを行います。

## 注意

ファームウェア書き込み時は、ミニ四駆側の電源をオフにしてからUSB接続してください。

## 画面がすぐ閉じる場合

ZIP内から直接実行している可能性があります。必ず「すべて展開」してから実行してください。

それでも失敗する場合は、`Mini4AI_flash_log.txt` の内容を確認してください。
