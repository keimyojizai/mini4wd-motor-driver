# 本体へ保存とスタンドアローン起動

このページでは、Webアプリで設定した内容をXIAO MG24 Sense本体へ保存し、BLE接続なしで走行開始する方法を説明します。

## 用語

| 用語 | 意味 |
|---|---|
| 一時適用 | Webアプリの「走行開始」時に、現在の画面設定を本体へ送って走行すること。電源を切ると残りません。 |
| 本体へ保存 | Webアプリの「本体へ保存」ボタンで、設定をXIAO MG24 Sense本体の不揮発メモリへ保存すること。 |
| スタンドアローン起動 | 保存済み設定を使い、BLE接続なしで本体だけで自動スタートすること。 |

## 保存される内容

「本体へ保存」で保存される対象は、主に以下です。

- 通常速度
- ソフトスタート開始Duty
- 認識調整パラメータ
- ルール設定
- 待機時間、ブレーキ時間、低出力制御
- 電圧補正設定
- 周回認識設定

Webアプリ上の表示位置やカードの並び順など、ブラウザ側だけの表示設定は本体には保存されません。

## Webアプリでの使い方

1. Webアプリを開きます。
2. XIAO MG24 SenseへBLE接続します。
3. 認識調整、ルール、電圧補正、周回認識を設定します。
4. 必要に応じて「走行開始」で動作確認します。
5. スタンドアローン起動で使いたい設定が決まったら、**「本体へ保存」** を押します。
   - 「本体へ保存」は、画面上部のヘッダー、走行コントロール欄、ルール設計欄にあります。
   - どの場所のボタンを押しても、保存される内容は同じです。
6. 「本体へ保存しました」と表示されれば保存完了です。

## 走行開始と本体へ保存の違い

Webアプリの「走行開始」は、現在の画面設定を一時的に本体へ送って走行します。

そのため、Webアプリ上で設定を変えて走行できていても、**本体へ保存を押していない場合、次回のスタンドアローン起動には反映されません。**

スタンドアローン起動で使いたい設定は、必ず「本体へ保存」を押してください。Webアプリでは、押し忘れを防ぐために画面上部にも保存ボタンを配置しています。

## スタンドアローン起動手順

保存済み設定がある状態で、以下の手順を行います。

1. ミニ四駆側の電源をオフにします。
2. 車体を裏返しの状態にします。
3. 裏返しのままミニ四駆側の電源をオンにします。
4. 車体を表向きに戻してコースに置きます。
5. 約3秒後に、保存済み設定で自動スタートします。

このモードでは、WebアプリやBLE接続を使わずに走行開始できます。

## 注意

- ルールが0本の状態を保存すると、スタンドアローン起動では意図した制御ができません。
- 認識調整やルールを変更しただけでは、本体の保存済み設定は更新されません。
- 設定変更後にスタンドアローン起動で使う場合は、毎回「本体へ保存」を押してください。
- 走行前に、通常のWebアプリ接続で一度動作確認してから保存することを推奨します。

## うまく動かない場合

- スタンドアローン起動しない場合は、まずWebアプリでBLE接続し、ルールが保存されているか確認してください。
- 設定を変更したのに反映されない場合は、「本体へ保存」を押したか確認してください。
- それでも動作しない場合は、[トラブルシュート](troubleshooting.md) を参照してください。
