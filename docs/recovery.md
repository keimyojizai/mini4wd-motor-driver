# 書き込み失敗時の復旧手順

## まず確認すること

- USBケーブルが充電専用ではないこと。
- USBハブを介さずPCに直接接続すること。
- WebアプリやArduino IDEのシリアルモニタを閉じること。
- ミニ四駆側の電源をオフにしてからUSB接続し、作業すること。
- 別のUSBポートを試すこと。

## 症状1: デバイスが選べない / ポートが出ない

1. USBを抜きます。
2. 数秒待って挿し直します。
3. `arduino-cli board list` またはArduino IDEのPortを確認します。
4. それでも出ない場合は、別のデータ通信対応USBケーブルを使います。

## 症状2: 書き込み途中で失敗する

1. Webアプリを閉じます。
2. Arduino IDE、シリアルモニタ、他のターミナルを閉じます。
3. 再度書き込みます。
4. 失敗が続く場合は、Windowsの管理者権限PowerShellまたはターミナルから実行します。

## 症状3: XIAO MG24が反応しない

XIAO MG24では、Deep Sleep等の状態によって書き込みしづらくなるケースがあります。

Seeedの復旧手順では、**PC1をGNDに落とした状態でリセット** し、アップロード可能な待機状態に入れる方法が案内されています。

手順:

1. XIAO MG24 SenseのPC1ピンとGNDを一時的に接続します。
2. その状態でRESETします。
3. 書き込みツール、またはArduino IDEから再書き込みします。
4. 書き込み後、PC1とGNDの接続を外します。

## 注意

PC1とGNDの短絡は復旧用の一時操作です。通常使用時に接続したままにしないでください。

## 最終手段

それでも復旧できない場合は、Seeed公式のXIAO MG24 unbricking手順、またはOpenOCD/flash erase手順を確認してください。
